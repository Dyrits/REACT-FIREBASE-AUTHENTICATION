# React Firebase Authentication

An authentication application built with React and Firebase.

## About The Project

A React application implementing an authentication flow with Firebase: sign up, sign in, sign out, password forget and password change, plus account, admin, home, landing, navigation and session components (see `src/components`).

Note: `package.json` does not currently list a `firebase` dependency, although a `src/components/Firebase` directory is present.

## Built With

- React (Create React App)
- React Router

## Getting Started

Install the dependencies with `npm install`, then start the development server with `npm start` and open http://localhost:3000. A Firebase project configuration is required for the authentication features.
